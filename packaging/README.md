# Packaging

| | |
|---|---|
| Fedora / COPR | [`fedora/armory.spec`](fedora/armory.spec): binary, man page, bash/zsh/fish completions; `%check` runs the test suite |
| macOS / Homebrew | [`homebrew/armory.rb`](homebrew/armory.rb): `brew install --build-from-source ./packaging/homebrew/armory.rb` |
| Portable archive | [`dist.sh`](dist.sh): `packaging/dist.sh [target]` → `target/dist/armory-<version>-<target>.tar.gz` |

To release: bump `version` in `Cargo.toml` and `fedora/armory.spec`, push tag `v<version>`.
[`release.yml`](../.github/workflows/release.yml) builds the portable archive with `dist.sh` on Linux x86_64,
macOS arm64 and macOS x86_64, then creates the GitHub Release with the archives and `SHA256SUMS`.
Its job summary prints the `url`/`sha256` of the tag's source archive: paste them into
`homebrew/armory.rb` (build-from-source formula) and commit. Pushes to `rust-rebuild` that touch
`packaging/**` or the workflow run the same builds as a dry run (artifacts only, no Release).
The man page and completions are generated by
the binary (`armory manpage`, `armory completions <shell>`).
For an air-gapped signing computer, copy the portable archive and run with `--datadir` on removable or
encrypted storage.
