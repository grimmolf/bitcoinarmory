# Packaging

| | |
|---|---|
| Fedora / COPR | [`fedora/armory.spec`](fedora/armory.spec): binary, man page, bash/zsh/fish completions; `%check` runs the test suite |
| macOS / Homebrew | [`homebrew/armory.rb`](homebrew/armory.rb): `brew install --build-from-source ./packaging/homebrew/armory.rb` |
| Portable archive | [`dist.sh`](dist.sh): `packaging/dist.sh [target]` → `target/dist/armory-<version>-<target>.tar.gz` |

The release tarball and the formula's `sha256` are produced when a `v<version>` tag is pushed. The man
page and completions are generated by the binary (`armory manpage`, `armory completions <shell>`).
For an air-gapped signing computer, copy the portable archive and run with `--datadir` on removable or
encrypted storage.
